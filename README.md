# MonSec CTF Writeups

Solutions and explanations for challenges MonSec has run or competed in.

## This repository publishes to monsec.io

A writeup merged here is picked up automatically and appears as an article on
monsec.io, tagged with its competition, category and difficulty. There is no
second step and nothing to copy anywhere.

To add one:

1. Copy `writeup-template.md` into a folder named for the competition, for
   example `ductf-2025/my-challenge.md`.
2. Fill in the block at the top of the file. Those fields decide how the
   article appears; the template explains each one.
3. Open a pull request.

## Writing it somewhere else as well

If you have already posted the writeup on your own blog or on Medium, put that
link in the `canonical` field. The article on monsec.io then carries a link
back to it, so your version stays the one that gets the traffic and the credit.

## Images

Screenshots are copied to MonSec's own storage when a writeup is published,
rather than hotlinked. The DUCTF 2023 writeups in this repository are why: every
screenshot in them pointed at one member's Medium account, so the club's only
record of that competition would have disappeared along with it.
